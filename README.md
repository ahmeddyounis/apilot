# APilot — AI Invoice Intelligence API

An agentic accounts-payable automation engine: extracts structured data from invoice
PDFs and images with a vision LLM, validates it with deterministic business rules,
runs autonomous 3-way matching against purchase orders and receiving records, catches
duplicates and fraud signals, and routes exceptions to a human review queue — behind a
production-grade FastAPI service with a field-level evaluation harness.

> **Status:** under active development. The full README (architecture, API reference,
> eval results) lands with the final milestone.
